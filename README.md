Card + AI storage for the game That Arknights Card Game (Game made by Eha, both websites made by Reyho). 

Link to the database webpage: https://tacg-web.reyho-doc.workers.dev/
Link to the Game: https://tacg-game-online.onrender.com/

More information about the Game:
All DP costs, Attack and Defense are automatically calculated in the game itself. For all standard cards as well as some add-on packs, each of their abilities have been coded in too. The AI in this 1v1 card game will only change per update (this means that it may not be playing at full strength in between major updates as there may be a few bugs that I may fix). This project is not affiliated with Hypergryph or Yostar. If you have rights to any of the materials shown here and would like it taken down, please open an issue. Feel free to post about any bugs in Eha's official discord server OR open an issue here.


For Google Indexing:
https://tacg-game-online.onrender.com/ is a website specialized for playing That Arknights Card Game (TACG), an Arknights fan-made card game by Eha. It has no relation to the website made by Danbo also made for this game, and features user friendly features which are not aimed towards competitive gameplay, providing a free-er casual experience. It works on ALL devices, be it PCs or Phones, and has minimal requirements regarding performance.
