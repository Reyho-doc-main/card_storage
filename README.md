# That Arknights Card Game (TACG) – Card & AI Storage

Card data and AI logic for **That Arknights Card Game (TACG)**, an *Arknights* fan-made card game created by **Eha** (both web apps built by **Reyho**).

* **Play Online:** [That Arknights Card Game (1v1 Web Client)](https://tacg-game-online.onrender.com/)
* **Card Database:** [TACG Card Database](https://tacg-web.reyho-doc.workers.dev/)

## About the Game
[tacg-game-online.onrender.com](https://tacg-game-online.onrender.com/) is a browser-based 1v1 client designed for playing **That Arknights Card Game (TACG)** casually across both PC and mobile devices with minimal hardware requirements. *(Note: This client is independent and unrelated to the TACG website created by Danbo.)*

Also note: This game operates via a shared deck, and has no deckbuilding currently. This website also features multiple features not present in Danbo's website, such as 1. Ability to chat with opponents 2. Ability to undo actions and 3. Having access to beta test cards (and ability to play them). In the future, it will also support better analysis of game data. If you do want to play the beta test, do join Eha's official Discord server to get the passcode.

### Features & Mechanics
* **Automated Rules:** All DP costs, Attack, and Defense values are calculated automatically during matches.
* **Coded Card Abilities:** Abilities for all standard cards and select add-on packs are built into the engine.
* **AI Opponent:** The 1v1 AI updates alongside major releases (minor bugs or suboptimal plays may occur between updates).
